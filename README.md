# 📐 数模助手 · 数学建模竞赛真题库

全国大学生数学建模竞赛（CUMCM）学习辅助工具。第一阶段为**真题库**：收录近 10 年（2016-2025）国赛真题，支持按年份 / 组别 / 题型筛选与关键词搜索；第二阶段将开发 **AI 提示词生成器**。

技术栈：Vue 3 + Vite（纯前端，零后端），部署于 GitHub Pages。

## 功能

- 📚 **真题检索**：2016-2025 共 10 年 54 道真题，每道题提供官网赛题压缩包下载链接
- 🔍 **多维筛选**：年份 / 组别（本科、本专科、专科）/ 11 种题型标签（评价、预测、优化、决策、统计、分类、规划、概率、图像处理、物理模型、几何）+ 关键词搜索
- 🏷️ **题型标签体系**：为第二阶段「AI 提示词生成器」积累算法分类数据
- 📄 **论文模板**：cumcmthesis LaTeX 国赛论文模板介绍与上手指引

## 部署

仓库已配置 GitHub Actions（`.github/workflows/deploy.yml`），推送 `main` 分支后自动构建并发布到 GitHub Pages。

## 数据说明

- 赛题链接来自全国大学生数学建模竞赛官网（mcm.edu.cn）
- 题目名称与题型标签整理自公开资料，如有出入以官方赛题 PDF 为准；部分专科组 E/F 题题名暂缺
